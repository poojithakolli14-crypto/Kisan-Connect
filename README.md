# 🌾 Kisan Connect

## AI-Driven Platform for Farmers, Buyers, FPOs and Mandis

Kisan Connect is an AI-powered platform designed to connect farmers,
buyers, FPOs, mandis and agricultural commodities across India.

## 🚀 Working Prototype

👉 [Open Kisan Connect Prototype](https://www.figma.com/make/7TzxVQMO1xfMsSS9zMGwG0/Kisan-Connect-Mobile-Prototype?fullscreen=1&t=Ikm41wQHxfbHWHjO-1&code-node-id=0-6)

## ✨ Key Features

- 🌱 Farmer Crop Listing
- 💰 Market Price Information
- 🤝 Farmer-Buyer Connection
- 🚚 Transportation Support
- 🤖 AI-Driven Agricultural Insights
- 🏪 FPO and Mandi Connectivity

## 🛠️ Technology Stack

- React
- Node.js / Flask
- AI/ML
- PostgreSQL
- APIs
- Weather and Agricultural Data

## 🎯 Objective

To provide farmers with better market access, transparent price
information, reliable buyers and efficient transportation support.
